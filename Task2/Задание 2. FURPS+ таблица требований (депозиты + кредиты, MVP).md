
 FURPS+ таблица по итогам анализа депозитного и кредитного направлений. Колонка **ASR** показывает, является ли требование архитектурно-значимым (Architecturally Significant Requirement). В колонке **Комментарий** — обоснование, в том числе для дополнительных требований, которые явно не прозвучали, но критичны для решения.

**Легенда категорий:** 
F — Functionality, 
U — Usability, 
R — Reliability, 
P — Performance, 
S — Supportability, 
«+» — Ограничения Design constraints / Implementation / Interface / Physical.
